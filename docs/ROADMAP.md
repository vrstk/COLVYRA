# COLVYRA Roadmap

- **M0 (initial scaffold):** Kotlin/Compose, Android folder picker, file list, media filter, persisted collection names, theme switch, CI debug build.
- **M1:** thumbnail grid and list, viewer, move/copy/rename/delete on user-granted files, MediaStore support, resilient navigation, tests.
- **M2:** Room database, virtual collections with references to local/cloud files, tags, search, durable IDs and backups.
- **M3:** Mail.ru Cloud and WebDAV, credential security, capability-based connectors and transfer queue.
- **M4:** internal browser, bookmarks, permissible downloads and share intents.
- **M5:** performance, accessibility, regression tests, signed alpha APK.
- **Future:** Google Drive, Google Photos, Telegram, VK, Reddit (subject to API authorization), additional cloud/NAS services.

M0 does not yet implement any cloud or social connectors.
